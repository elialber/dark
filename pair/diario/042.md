  --listar [caminho]`); módulo e caminho juntos com `--listar` dão código 2.
  Fora de um repositório git, `--listar` também dá 2 (precisa do manifesto).
- `adicionar` sem módulo e sem `--listar`: código 2.
- Mensagens de erro de `iniciar` continuam com o prefixo `dark iniciar`; as
  de `adicionar`, `dark adicionar`. A frase final do `--aplicar` passou a
  usar o nome do módulo (`dark remover <módulo>`); para `base` é a mesma.
- Módulo desconhecido é checado antes do caminho.
- `register` recusa um segundo módulo diferente com o mesmo nome.
- `verificar` de módulo nunca aplicado: código 1 ("o módulo não foi
  aplicado"), não 2.
