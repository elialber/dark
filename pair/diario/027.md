## Item 1: coleta no mesmo segundo

**Decisão** (padrão a confirmar; o revisor registra em `docs/decisoes.md`):
a coleta grava o registro no próximo segundo livre, em vez de mudar o
esquema ou esperar. Motivos: não exige migração (o banco antigo continua

desvio é de segundos. Custo: `started_at` de uma coleta pode estar

## Item 2: a auditoria lê do banco

**Padrão a confirmar:** `dark auditar` não coleta sozinho (E10 deixou em
aberto); `--coletar` coleta antes, mostrando o resumo no erro padrão (a
saída padrão é o relatório).

Regras como implementadas:

- Usa o banco quando o arquivo existe, abre, e conhece o repositório
  (pelo commit inicial, E15; vale qualquer commit inicial do repositório).
  Com `--todos`, usa todas as sessões do banco.
- Senão, auditoria direta, com "Fonte: leitura direta...; o banco não foi
  usado: <motivo>" no cabeçalho. Motivos: pedido com `--direto`;
  `--excluir-pasta` (o banco não guarda a pasta); sem banco; arquivo
  vazio; não conhece o repositório; sem sessões; erro do banco traduzido.
- `--banco` usa a mesma recusa de `dark coletar` (dentro do repositório
  auditado, ou de qualquer repositório git sem ignorar): código 1, nada
  gravado.
- `--direto` com `--coletar`: código 2.
- Arquivo de 0 bytes não é aberto (abrir criaria o esquema no arquivo do
  usuário): cai na leitura direta.
- Abrir um banco de versão antiga o migra (comportamento de `open_store`,
  com cópia de segurança). Leitura que escreve; aceitei por ser só
  migração para frente.
- `--dias` e `--ate` filtram pelo início da sessão (na leitura direta,
  `--ate` ignora registros depois do instante, dentro de sessões; aqui
  uma sessão é inteira ou nada).
- Com `--todos`, a seção "O que está instalado" não aparece pelo banco
  (o inventário atual de cada repositório não é relido).

**O que o banco não guarda e como o relatório diz:** custo por pedido e
os pedidos mais caros, pedidos com algum sinal de intervenção, chamadas de
commit silenciosas, com erro ou em subagentes, hooks em subagentes, o
motivo de uma chamada sem ligação, amends por comando versus git, o nome
dos tipos e campos desconhecidos (aparece `?` com o total), a repartição
por parte do peso fixo (só os três grupos), e as versões do Claude Code
por sessão (uma só por sessão). Cada um dessas linhas diz "o banco não
guarda; use `--direto`" ou some, nunca mostra um zero que pareça fato.
