## Decisões

- **O wheel não leva o plugin.** `plugin/` fica fora de `src/`, e
  `packages.find` só olha `src`. O plugin se instala pelo checkout
  (`claude --plugin-dir`). Um teste registra a decisão.
- **Limite da descrição:** 1024 caracteres e nome até 64, `[a-z0-9-]`
  (limites de frontmatter de skill do Claude Code, de memória; o
  validador não os aponta). Padrão a confirmar.
- **Privacidade:** padrões copiados de `tests/test_distribution.py`
  (os helpers de lá são privados). A URL do repositório nas skills é o
  mesmo marcador do README: `pip install "git+<URL do repositório>"`.
- **`dark --versao` não existe** no CLI atual (`src/dark/cli.py`). A skill
  trata isso: cai para `command -v dark` e `python -m pip show dark`, e
  nunca instala sozinha. Se o lote 011 ou outro adicionar `--versao`, a
  skill já funciona.
- O teste exige exatamente as skills `auditar` e `coletar` e nada além de
  `.claude-plugin`, `skills` e `README.md` na raiz do plugin, para o
  scaffold não crescer sem decisão (`docs/visao.md`).
